# Project #1 · To-Do List

일정 제목과 날짜를 등록하고 완료 여부를 관리하는 브라우저 기반 일정 관리 프로그램입니다.

## 실행과 파일 구성

`todo.html`을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 서버는 필요하지 않습니다.

| 파일 | 역할 |
|---|---|
| `todo.html` | 일정 입력 폼, 목록, 경고 모달 구조 |
| `todo.css` | 데스크톱·모바일 화면과 상태별 스타일 |
| `todo.js` | 배열 관리, 입력 검증, 렌더링, 이벤트 처리 |

## 요구사항과 구현

| 번호 | 기능 | 구현 |
|---|---|---|
| FR1 | 일정 추가 | 제목과 날짜를 검증한 뒤 `taskArr`에 저장 |
| FR2 | 일정 삭제 | 선택한 일정 id를 배열에서 즉시 제거 |
| 추가 | 완료 처리 | 체크박스로 `done` 상태 전환 |
| 추가 | 필수 입력 검사 | 빈 입력창과 경고 모달 표시 |
| 추가 | 7일 필터 | 오늘부터 6일 뒤까지의 일정만 표시 |

일정 데이터는 `{ id, title, date, done }` 객체로 `taskArr` 배열에 저장됩니다.

## 주요 함수

| 함수 | 설명 |
|---|---|
| `isEnteredAll()` | 제목과 날짜가 모두 입력되었는지 확인 |
| `validateTaskFields()` | 필수 입력 오류를 각 입력창에 표시 |
| `addTask(event)` | FR1 검증 후 일정 객체를 배열에 추가 |
| `deleteTask(id)` | FR2 해당 id의 일정을 배열에서 삭제 |
| `toggleDone(id)` | 일정의 완료 상태를 반전 |
| `isWithinWeek(dateStr)` | 날짜가 오늘부터 7일 범위인지 확인 |
| `renderTasks()` | 배열과 필터 상태를 목록 화면에 반영 |
| `resetTaskForm()` | 입력값과 검증 표시를 초기화 |

## 화면 이벤트

| 사용자 동작 | 이벤트·함수 | 화면과 데이터 변화 |
|---|---|---|
| 추가 버튼 클릭 또는 Enter | `submit` → `addTask()` | 유효하면 배열과 목록에 추가, 입력 폼 초기화 |
| 빈 값으로 추가 | `submit` → `validateTaskFields()` | 빈 칸 오류와 경고 모달 표시, 배열은 변경되지 않음 |
| 완료 체크박스 변경 | `change` → `toggleDone()` | `done` 값과 취소선·흐림 상태 변경 |
| 삭제 버튼 클릭 | `click` → `deleteTask()` | 확인창 없이 해당 일정을 즉시 삭제 |
| 7일 필터 변경 | `change` → `renderTasks()` | 조건에 맞는 일정과 표시 건수 갱신 |
| 모달 확인·배경 클릭·Escape | `click`/`keydown` → `closeAlert()` | 경고 모달을 닫고 이전 위치로 초점 복귀 |

## 제한사항

- 데이터는 메모리 배열에만 저장되므로 새로고침하면 초기화됩니다.
- 일정 수정과 DB 저장은 과제 범위에 포함하지 않았습니다.
