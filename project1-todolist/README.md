# Project #1 · To-Do List

신입사원 OJT 4주차 최종 프로젝트 - To-Do List (일정 관리) 구현

## 실행 방법
`todo.html` 파일을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 서버 구동이 필요 없습니다.

## 파일 구성
- `todo.html` : 화면 구조
- `todo.css` : 스타일
- `todo.js` : 기능 로직 (일정 추가/삭제 등)

## 기능 요구사항
- FR1) 일정을 추가할 수 있어야 합니다.
- FR2) 일정을 삭제할 수 있어야 합니다.
- (추가 구현) 일정 완료 처리, 필수 입력 체크, 이번 주(오늘~7일) 필터 보기

자세한 설명은 별도로 제출한 결과 보고서 문서를 참고해주세요.
