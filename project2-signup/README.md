# Project #2 · 회원가입

회원 정보를 검증한 뒤 데이터베이스 대신 JavaScript 배열에 저장하는 간단한 회원가입 프로그램입니다.

## 실행과 파일 구성

`signup.html`을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 서버는 필요하지 않습니다.

| 파일 | 역할 |
|---|---|
| `signup.html` | 회원가입 폼과 완료·경고 모달 구조 |
| `signup.css` | 입력 상태, 모달, 반응형 화면 스타일 |
| `signup.js` | 배열 저장, 중복 검사, 비밀번호 검증, 이벤트 처리 |

## 요구사항과 구현

| 번호 | 기능 | 구현 |
|---|---|---|
| FR1 | 배열 저장 | `{ id, name, password, createdAt }` 형태로 `userArr`에 저장 |
| FR2 | 아이디 중복 검사 | 대소문자 구분 없이 배열의 기존 아이디와 비교 |
| FR3 | 비밀번호 규칙 검사 | 자체 규칙과 확인란 일치 여부를 실시간 검사 |
| 추가 | 아이디 형식 검사 | 영문·숫자 4~12자만 허용 |
| 추가 | 표시·숨김 | 두 비밀번호 입력란을 버튼으로 전환 |
| 추가 | 필수 입력·완료 안내 | 경고 모달과 가입 완료 모달 표시 |

### 비밀번호 규칙

1. 영문, 숫자, 특수문자를 각각 한 글자 이상 포함한 8~16자
2. 아이디 문자열 포함 금지
3. 동일 문자 3회 연속 사용 금지
4. 비밀번호 확인란과 일치

## 주요 함수

| 함수 | 설명 |
|---|---|
| `isEnteredAll()` | 네 개의 필수 입력값이 모두 있는지 확인 |
| `isIdFormatValid(id)` | 아이디의 문자 종류와 길이를 검사 |
| `isDuplicate(id)` | FR2 배열에서 아이디 중복 여부를 확인 |
| `checkDuplicateId()` | 형식·중복 검사 후 확인 완료 아이디 저장 |
| `isValidPassword()` | FR3 자체 비밀번호 규칙 검사 |
| `paintPasswordMatch()` | 확인란의 일치 여부를 표시 |
| `togglePasswordVisible()` | 비밀번호 표시 상태와 버튼 문구 변경 |
| `registerUser()` | FR1 회원 객체를 배열에 저장 |
| `validation(event)` | 전체 가입 조건을 순서대로 검사 |
| `resetForm()` | 가입 후 입력·검증·표시 상태 초기화 |

## 화면 이벤트

| 사용자 동작 | 이벤트·함수 | 화면과 데이터 변화 |
|---|---|---|
| 중복확인 클릭 | `click` → `checkDuplicateId()` | 형식·중복 결과 표시, 사용 가능 아이디 기록 |
| 확인한 아이디 수정 | `input` | 기존 중복확인 결과 무효화 |
| 비밀번호 입력 | `input` → `isValidPassword()` | 규칙 만족 여부를 실시간 표시 |
| 원 비밀번호 수정 | `input` → `paintPasswordMatch()` | 이미 입력된 확인란을 즉시 다시 검사 |
| 눈 버튼 클릭 | `click` → `togglePasswordVisible()` | 비밀번호 표시·숨김 전환 |
| 발급 버튼 클릭 또는 Enter | `submit` → `validation()` | 통과 시 배열 저장·폼 초기화·완료 모달 표시 |
| 모달 확인·배경 클릭·Escape | `click`/`keydown` | 현재 모달을 닫고 입력 흐름으로 복귀 |

## 제한사항

- 배열 데이터는 새로고침하면 초기화되며 DB와 실제 로그인 세션은 없습니다.
- 과제 조건에 따라 비밀번호를 배열에 평문으로 저장합니다. 실제 서비스에서는 해시 처리가 필요합니다.
- 이메일 인증, 비밀번호 찾기, 서버 측 검증은 과제 범위에 포함하지 않았습니다.
