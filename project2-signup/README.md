# Project #2 · 회원가입

신입사원 OJT 4주차 최종 프로젝트 - 회원가입(사원증 발급) 구현

## 실행 방법
`signup.html` 파일을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 서버 구동이 필요 없습니다.

## 파일 구성
- `signup.html` : 화면 구조
- `signup.css` : 스타일
- `signup.js` : 기능 로직 (중복확인, 비밀번호 규칙 검증 등)

## 기능 요구사항
- FR1) 아이디 중복 체크가 되어야 합니다.
- FR2) 비밀번호에 자체 규칙을 만들고, 정상성 체크 기능이 있어야 합니다.
- (추가 구현) 아이디 길이 체크, 비밀번호 표시/숨기기, 필수 입력 체크, 가입완료 팝업

자세한 설명은 별도로 제출한 결과 보고서 문서를 참고해주세요.
