# 신입사원 OJT 4주차 최종 프로젝트

별도 서버나 데이터베이스 없이 브라우저에서 실행하는 두 개의 독립적인 JavaScript 프로젝트입니다.

| 프로젝트 | 필수 구현 | 상세 문서 |
|---|---|---|
| [Project #1 To-Do List](./project1-todolist) | 일정 추가, 일정 삭제 | [README](./project1-todolist/README.md) |
| [Project #2 회원가입](./project2-signup) | 배열 저장, 아이디 중복 검사, 비밀번호 규칙 검사 | [README](./project2-signup/README.md) |

## 실행 방법

1. To-Do List는 `project1-todolist/todo.html`을 브라우저에서 엽니다.
2. 회원가입은 `project2-signup/signup.html`을 브라우저에서 엽니다.
3. 설치나 서버 실행은 필요하지 않습니다.

## 제출 문서

- `Project1_ToDoList_결과보고서.docx`
- `Project2_회원가입_결과보고서.docx`

각 보고서에는 요구사항별 구현 내용, 함수 설명, 이벤트 흐름, 실제 실행 화면, 테스트 결과와 제한사항이 포함되어 있습니다.
